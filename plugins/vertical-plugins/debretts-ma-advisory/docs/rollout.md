# Rollout

Nothing here needs a training course. The people who get the most out of Claude are the
ones who use it on real work in the first fortnight rather than saving it for later. The
plan below is sequenced so that the firm's method is captured while the team is still
forming habits.

Owners are roles. Holly owns access, connectors, Projects and the skill library.

## Days 1–30 — make it the default place work starts

| # | Action | Owner | Done when |
|---|---|---|---|
| 1 | Everyone signed in on their Debrett's account, role and sector set in Settings | Holly | Every seat active |
| 2 | Firm Standards Project stood up: brand, templates, tone examples, prompt library | Holly | Standing instructions pasted, templates loaded |
| 3 | Install the vertical plugin so `/screen`, `/buyers`, `/im`, `/verify` are available | Holly | Commands resolve for every user |
| 4 | Office add-ins installed — Excel, PowerPoint, Word, Outlook | Each user | Panel opens on a live piece of work |
| 5 | One live mandate converted to a Project with `/mandate` | Deal executive | Data pack loaded, standing instructions written |
| 6 | Every user runs the Golden Prompt structure on one real task a day | Each user | Fortnight of daily use |
| 7 | `debretts-verify` used before every external send | Each user | It is the habit, not a reminder |

**Success at 30 days:** work starts inside a Project rather than a blank chat, and nothing
client-facing leaves without a verification pass.

## What to measure

Four questions, answered with numbers:

1. **Hours to first draft.** Buyer universe, IM section, Q&A pack — before and after.
2. **Rework rate.** How often is an output edited for longer than it would have taken to
   write? A high rate is a prompt problem or a Project-hygiene problem, not a tool problem.
3. **Verification catches.** How many figures did the verification pass flag before an
   external send? This number should never be zero, and if it is, the pass is not running.
4. **Origination throughput.** Names screened, calls made, conversations opened, per
   partner month.

## The failure modes to watch for

- **Working in blank chats.** The single largest cause of disappointing output and wasted
  allowance.
- **Projects going stale.** Superseded drafts left in place produce confidently wrong
  answers.
- **Agents used for one-step work.** Expensive and slower than chat.
- **Verification treated as a formality.** It is the control the whole system rests on.
- **Skills nobody wrote down.** If the method lives only in one person's prompts, the firm
  has not gained anything.
