# Offer comparison

Headline price is the least informative number in an offer letter. The work is converting
five differently structured proposals into one comparable table, and then saying which we
would recommend and why.

## Step 1 — Normalise to net proceeds

For each offer, build the bridge from headline to cash-to-shareholder at completion:

| Line | Offer A | Offer B | Offer C |
|---|---|---|---|
| Headline enterprise value | | | |
| Less: net debt (basis and date) | | | |
| Cash-free debt-free adjustment | | | |
| Working capital peg and mechanism | | | |
| Equity value | | | |
| Less: deferred consideration | | | |
| Less: earn-out (maximum and expected) | | | |
| Less: rollover or reinvestment required | | | |
| Less: escrow or retention, and release period | | | |
| Less: estimated transaction costs and taxes (flag as estimate) | | | |
| **Cash to shareholders at completion** | | | |
| **Total potential consideration** | | | |

State the assumptions under the table. Never present an earn-out at maximum as though it
were consideration.

## Step 2 — Score the terms that move value after signing

| Dimension | What to record |
|---|---|
| Structure | Cash, deferred, earn-out, rollover, paper. Currency |
| Earn-out mechanics | Metric, basis, period, control of the business during it, measurement disputes |
| Conditionality | Financing, diligence remaining, regulatory, third-party consents, board or IC approval |
| Funding evidence | Equity commitment, debt terms, whether a credit committee has approved |
| Warranties and indemnities | Cap, basket, survival, W&I insurance, tax covenant |
| Management | Roles, terms, incentive package, tie-in period |
| Timetable | Exclusivity requested, signing and completion dates, diligence remaining |
| Deliverability | Track record of completing, behaviour so far in the process, adviser quality |

## Step 3 — Rank on three axes, separately

Do not collapse these into one score. The vendor's weighting between them is theirs.

1. **Value** — net proceeds at completion, then total potential consideration.
2. **Certainty** — conditionality, funding evidence, diligence remaining, track record.
3. **Fit** — the vendor's non-price objectives: continuity for the team, the business's
   future, confidentiality, speed.

## Step 4 — The recommendation

- One paragraph: which offer we would take forward and why, in the vendor's terms.
- The two or three points to negotiate with each party, and the order to raise them.
- What each party is likely to move on, on the evidence of their behaviour so far.
- What we would say to the parties we are not taking forward, and when.

## Step 5 — Bid letter review

Reading a bid letter, list separately: what is committed, what is conditional, what is
silent, and what is drafted to look like a commitment and is not. Silence on a material
term is a position, not an oversight — record it and raise it.

## Output

1. The normalised comparison table with assumptions stated.
2. The terms matrix.
3. Three rankings, plus the recommendation.
4. Negotiation points per party, in priority order.
5. Every `[UNVERIFIED]` item — figures the offer does not evidence, and what to ask for.

## Guardrails

- No invented deal terms, and no assumption about a term the letter does not state. If it
  is silent, record it as silent.
- Tax and legal consequences are flagged for the client's tax and legal advisers. Debrett's
  does not give tax or legal advice, and this comparison says so on its face.
- Estimated costs and taxes are labelled estimates every time they appear.
- The recommendation is a Debrett's view for the vendor's decision. The vendor decides.
